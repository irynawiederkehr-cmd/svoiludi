# Картинки «как на телефоне» — один стиль для всего сайта (10.10.2026)

Здесь скрипты, которыми сделаны картинки телефона: галерея на странице «Как установить приложение» (prilozhenie/), крупные планы в подсказке установки (pwa-app.js) и снимки для «Копии svoiludi.ch». Правило Ирины: стиль элементов узнаваемый и повторяется быстро и одинаково — новые картинки телефона делать только этими скриптами. Полное описание стиля всех элементов — документ проекта «stil-elementov.md».

## Как пересобрать (из корня репозитория)
```
NODE_PATH=$(npm root -g) node _i18n/telefon/cap.js          # 1) снимки сайта 390 px, RU и UA → _i18n/telefon/shots/ (в git не идут)
NODE_PATH=$(npm root -g) node _i18n/telefon/mock.js         # 2) галерея: prilozhenie/img/ru|uk/*.jpg (телефон в рамке, 620×1228)
NODE_PATH=$(npm root -g) node _i18n/telefon/crop.js         # 3) крупные планы для подсказки: prilozhenie/img/ru|uk/s-*.jpg (780×300)
NODE_PATH=$(npm root -g) node _i18n/telefon/cap-kopiya.js   # снимки для страниц «Копии» (app/, knopki/) → shots2/
NODE_PATH=$(npm root -g) node _i18n/telefon/ramka.js <папка>  # те же снимки в рамке телефона и планшета → <папка>/app, <папка>/knopki
```
Пересобирать, когда меняется вид шапки, меню, вкладок или главной (на картинках видны настоящие страницы). Сначала собрать сайт (build, nav, pwa), потом снимки.

## Стиль картинки телефона (не менять без решения Ирины)
- Плитка 470×930, фон #E3E8D6 (шалфейный светлый), телефон 412×866 по центру, тень снизу.
- iPhone: рамка #1F1D1B 11 px, скругление 60 / экран 49, «островок» сверху, строка состояния 9:41, полоска «домой» внизу.
- Android: скругление 44 / экран 33, точка камеры, строка состояния 9:41, полоска жестов.
- Экраны браузеров — условные, без логотипов: Safari (адрес внизу, «Поделиться»), Chrome (адрес вверху, ⋮), встроенный браузер (✕, название, ⋯). Подписи меню — как в настоящих телефонах на русском и украинском.
- Нужная кнопка обведена: кольцо #E0572B 3,5 px с мягким ореолом.
- Значки «других приложений» на экране «Домой» — простые цветные квадраты (iPhone) или круги (Android) с линейными значками, без брендов.
- Сохранение: JPEG качество 74, масштаб 1.32 (галерея) или 2 (крупные планы).
