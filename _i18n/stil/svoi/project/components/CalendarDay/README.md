# CalendarDay

Как отмечаются дни во всех календарях сайта: праздник кантона — розовая заливка `holiday-bg` и название `holiday-ink`; школьные каникулы — зелёная полоса `school-line` снизу (отдельный слой).

- Праздники и каникулы всех 26 кантонов, у праздника — подсказка «?» (что за день, есть ли похожий у нас, как отмечают); списки праздников свёрнуты в строку-итог.
**Код и данные:** календари инструментов (`uchet-vremeni`, `chasy-po-klientam`, `zhurnal-perederzhki`), правила — «pravila-instrumentov.md».
