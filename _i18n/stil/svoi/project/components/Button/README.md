# Button

Кнопки обоих сайтов: прямоугольные с закруглением 12 px (`radius-btn`), жирный Manrope (`button`), мягкая тень снизу (`shadow-btn`).

- `.btn` — главное действие страницы, заливка `brown` (на svoiludi.ch тёмно-зелёная, на voznesenskaya.ch коричневая), текст `paper`.
- `.btn.free` — всё бесплатное («Открыть календарь», «+ Добавить»): `btn-free` + `on-btn`.
- `.btn.gold` — цена, главный продукт, «Скачать PDF»: `btn-gold` + `on-btn` (белый на горчице 3,3:1 — только жирный текст кнопки).
- `.btn.ghost` — второстепенное: контур `line`, текст `brown`.
- `.btn.sm` — маленькая (13 px) в строках и карточках.
- В шапке: «Подать заявку» (`.navcta`, контур `brown`) и «Поиск» (`.ss-btn`, белая пилюля с лупой; на широком экране только лупа).

**Нельзя:** круглые кнопки-пилюли (999 px) — это только метки; перелив и градиенты (перелив был только у «VIP-партнёр ТОП»); две кнопки `.btn` рядом — вторая всегда `.ghost`.
**Код:** правило формы — блок в `<head>` (`:is(.navcta,.btn,…){border-radius:12px!important}`), цвета — стили страниц и инструментов.
