# DirectoryCard — карточка специалиста в справочнике

`article.sp` на главной (и та же карточка в «Организациях», см. OrgCard). Здесь — образец «VIP-партнёр».

- Строка направления цветом направления (`--lc`) с иконкой; справа значок уровня (`.badge.tier`: «VIP-партнёр», «VIP-партнёр ТОП», «VIP-онлайн», «VIP-онлайн ТОП») с кружком «?» о платном размещении. У настоящих карточек справа в строке — сердечко с числом (`.lk`).
- Фото 4 : 5, 14 px — **всегда вверху и на одном уровне во всём ряду** (subgrid в сетке `.grid`, правило Ирины 10.10.2026). Рядом имя Forum, роль, фирма, строка категорий мелким серым через « · » (`.sp-cats`).
- Акция — красная рамка с пометкой «Реклама»; объявление «Ищет себе сотрудника» — серая пилюля.
- «Где», «Языки»; внизу «Позвонить» / «Подробнее» и круглая закладка «Мой список» (`.fav`, сохранённая — залита тёмным зелёным).
- Образцы — метка «Образец», вымышленные данные, без сердечек, в статьях не показываются. Бледный водяной знак «Свои люди · svoiludi.ch» — на каждой карточке.
- Карточки внутри каждой группы (ТОП, VIP, базовые) стоят в случайном порядке при каждом открытии (13.10.2026).

**Код:** index.html (`card()`, CSS в `<head>`).

**Разметка и стили здесь сняты с сайта** скриптом `_i18n/stil/svoi/grab.js` (что снимать — `grab-spec.js`). Поменялся элемент на сайте — `node _i18n/stil/svoi/grab.js DirectoryCard`, руками preview.html и раздел `@grab DirectoryCard` в bundle.css не правим.
