# InstallHint

Карточка снизу экрана с шагами установки: появляется через 8 секунд или при прокрутке, и по кнопке установки; «Не сейчас» прячет на 30 дней.

- `paper`, рамка `line`, `radius-hint`, `shadow-hint`; иконка сайта 52 px, заголовок Forum (`card-title`) с кружком «?», вводная `muted`.
- Шаги — номера в кружках `sage`; под ними крупные планы «Так это выглядит на телефоне» (полоски 780×300 из `_i18n/telefon/crop.js`, листаются вбок), ссылка «Пошаговая инструкция →» (страница prilozhenie/), на страницах инструментов — жёлтая пометка `mustard-soft` о резервной копии.
- Варианты: iPhone (Safari, «Поделиться»), Android без кнопки браузера (⋮), Instagram/Telegram («Открыть в браузере»), Android с кнопкой — одна кнопка «Установить приложение».
**Код:** `card()` в `assets/pwa-app.js`; проверка — `?install=ios|android|inapp`.
