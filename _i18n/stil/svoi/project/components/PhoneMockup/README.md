# PhoneMockup

Картинки «как на телефоне» делаются ТОЛЬКО скриптами `_i18n/telefon/` (README там же): настоящие снимки сайта в рамке телефона и условные экраны браузеров без логотипов.

- Плитка 470×930, фон `mockup-ground`; iPhone — рамка `mockup-bezel` 11 px, `radius-phone` 60 / экран 49, «островок», 9:41; Android — 44 / 33, точка камеры.
- Нужная кнопка обведена кольцом `ring` 3,5 px с ореолом.
- Значки «других приложений» — простые цветные квадраты (iPhone) или круги (Android) с линейными значками, без брендов.
- Галерея — JPEG 620×1228 (`mock.js`), крупные планы для подсказки — 780×300 (`crop.js`), страницы «Копии» — `ramka.js`. Пересобирать, когда меняется шапка, меню или главная.
