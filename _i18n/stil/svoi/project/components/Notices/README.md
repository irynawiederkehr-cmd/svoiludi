# Notices

Блоки, которые выделяют абзац по смыслу. Каждый вид — для одного смысла, не путать.

- `.warn` (`mustard-soft`, `radius-box`) — важное, что нельзя пропустить: заголовок жирным первой строкой.
- `.privnote` (`sage-soft`) — «Твои данные только у тебя» в начале инструментов.
- `.tm-calm` (`sage-soft`) — спокойная вводная, поддерживающие смыслы (законы как забота, всему своё время).
- `.imp` (пунктир `sage` 55 %, `paper`) — «Важно. Это образец…» внизу инструментов.
- `.exbar` (`mustard-soft`) — полоса «Это пример» с кнопкой возврата.
- `.warnbox` (`warn-bg`, рамка `warn-line`, текст `warn-ink`) — тревожное предупреждение со значком B; только для настоящего риска.
**Тон:** поддерживающе, с выходом — что сделать, к кому обратиться (см. правила текстов).
