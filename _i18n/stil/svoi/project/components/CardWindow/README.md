# CardWindow — окно карточки

`dialog.qm` — открывается «Подробнее» в справочнике и в «Организациях» (одна функция на оба раздела). Здесь — образец «VIP-партнёр ТОП» на телефоне.

- Шапка: фото (или медальон), метка «Образец…», направление и уровень, имя Forum, роль, фирма; крестик — круг 44 px.
- Акция специалиста — красная рамка, «Реклама», «Скачать флаер», «Воспользоваться акцией».
- Блоки `.d-block` с подписью маленькими заглавными: «Профиль» (от первого лица — правило 13.10.2026), «Услуги» плашками, **«Цены»** (`.pl-block`: короткая строка и раскрывашка «Весь прайс-лист · N услуг» с шевроном цвета направления, внутри список услуга · длительность · цена Forum; в предпросмотре из письма сразу открыт, сверху горчичная плашка «Проверьте, пожалуйста, цены»), **«Где найти в справочнике»** (пилюли `.gocat`: направление с иконкой и рамкой цвета направления, потом категории), «Формат», «Языки», «Особенности», объявления «Ищет себе сотрудника» с зелёным сердечком «некоммерческое», «Встречи, курсы и вебинары».
- Справа (на телефоне ниже) серый блок: «Где принимает» с «На карте · Маршрут · Скопировать адрес», «Контакты», кнопки — у настоящих карточек первым **сердечко с числом и уровнем** (`.lk.lk-big`: 0 — контур, 1–9 нежно-розовое, 10–49 розовое с бликом, 50+ малиновое с искоркой; рядом «?»), «В мой список» с числом (`.svb`), «В контакты», «Поделиться», «Визитка PNG», «Прайс-лист PNG», «Афиша и расписание» (13.10.2026: PDF, PNG и всё в календарь), «PDF» — **одна кнопка на один файл**. Внизу регистрация, дата проверки, номер карточки, «Сообщить».
- У организаций свои подписи и блоки «Форма», «Взносы» / «Цены», «Руководитель», «Важно»; Facebook и YouTube только в окне, в файлах их нет.

**Код:** index.html (`openCard`, `priceBlock`, `likeBtn`, `heartSvg`, `pvAfisha`), assets/afisha-org.js.

**Разметка и стили здесь сняты с сайта** скриптом `_i18n/stil/svoi/grab.js` (что снимать — `grab-spec.js`). Поменялся элемент на сайте — `node _i18n/stil/svoi/grab.js CardWindow`, руками preview.html и раздел `@grab CardWindow` в bundle.css не правим.
