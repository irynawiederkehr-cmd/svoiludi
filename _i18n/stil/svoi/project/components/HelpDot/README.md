# HelpDot

Кружок «?» 20 px у каждой опции, поля, переключателя или цифры, где новичок может не понять, что выбрать.

- Нажатие открывает короткое объяснение простыми словами («ты», без «справа/слева», без выдуманных цифр закона), с примером и, для взносов и сумм, — где эту цифру найти и источник с годом.
- Закрывается вторым нажатием, крестиком, нажатием мимо или Escape.
**Код:** `assets/help.js`, тексты в `window.HELP` на странице; украинский — `help.uk.js` собирается сам.
