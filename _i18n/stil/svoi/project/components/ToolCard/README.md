# ToolCard

Компактная карточка инструмента в статьях и «Моей ситуации»: слева маленький веер из настоящих страниц PDF, справа название, одна строка пользы и «Бесплатно · PDF · открыть →».

- Фон `mustard-soft`, `radius-btn`; страницы веера 56 px с тенью `shadow-fan`, разворот на 7° на каждую.
- Название — то, что человек получит («Журнал передержки животных», не «Мой журнал»).
- Страницы — только настоящие целые страницы PDF из инструмента (`instrumenty/preview/<инструмент>/N.jpg`, UA — `/uk/`).
**Код:** `.tool.tpv`, `.tfan` в `assets/temy.css`; большой веер на странице инструмента — `assets/pdffan.js` (PdfFan).
