# ListMarker — маркер списков «Росток»

Единый маркер всех маркированных списков обоих сайтов (решение Ирины 12.10.2026, 22:29: вариант 3 «Росток» из пяти; «на будущее запоминай… ставишь мне эти чёрные точки как в вордовском файле»). Стебелёк с двумя листиками — «растём и укрепляемся в новой стране».

- Цвет — цвет сайта: на svoiludi.ch шалфей `#66704F` (тёмная тема `#A9B98F`), на voznesenskaya.ch коричневый `#6E4F3C` (тёмная `#E1C2A6`). Листики — тот же цвет на 30 %.
- Рисунок — маска (`-webkit-mask`/`mask`), цвет — переменная `--sl-bul-c`, поэтому в тёмной теме и в цветных списках он перекрашивается сам. В карточках инструментов («Полезные инструменты») росток цвета инструмента (`--c`).
- Размер 1,15 em, слева 1,7 em отступа текста, верх 0,2 em — ровно по первой строке.
- Ставится сам: любой `ul` без класса и без id (в тексте, окне, подсказке «?», раскрывашке) и списки с классами `ul.ul`, `ul.marks`, `ul.facts`, `ul.k-rules`, `ul.effects`, `ul.regdoc`, `ul.big`, `ul.svplan`, `ul.sl-bul`, `.tool ul`, оглавление статьи `nav.toc` (с 14.10.2026, `assets/temy.css` — меню `nav` из общего правила исключены, поэтому у оглавления своё правило с тем же рисунком) (на voznesenskaya.ch `.pd-box ul`, `.lim-body ul`, `ul.pain`, `ul.res`, `ul.leaf`).
- Новый список с классом — допиши класс в `BUL_UL` (svoiludi: `_i18n/pwa.py`, voznesenskaya: `_i18n/shape.py`) или дай ему класс `sl-bul`. Список данных без маркера (строки, суммы, карточки) — класс `no-bul`.

**Нельзя:** стандартные чёрные точки (disc, «как в Word»), ромбики, квадратики, свои маркеры для отдельной страницы.
**Не трогаем:** нумерацию (`ol`, шаги с кружками-цифрами), галочки ✓ и плюсы в списках пакетов и «Как мы проверяем», красный треугольник предупреждений (WarningIcon), меню и вкладки.
**Код:** svoiludi.ch — блок `<style id="sl-bul-css">` в `<head>` каждой страницы (`_i18n/pwa.py`, BUL); voznesenskaya.ch — `<style id="vz-bul-css">` в блоке `<!--shape-->` (`_i18n/shape.py`).
