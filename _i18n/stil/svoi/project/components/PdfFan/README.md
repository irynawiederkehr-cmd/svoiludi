# PdfFan

Веер настоящих страниц готового PDF: человек сразу видит, какой файл получит. У каждого инструмента — на вкладке «Полезные инструменты» и под вступлением на странице инструмента.

- Блок «Так выглядит готовый файл», кружок «N страниц / 1 лист A4», подпись под веером; листается сам, стрелками, точками и пальцем; нажатие — крупно.
- Только целые страницы, никаких вырезанных кусков; страницы из PDF инструмента с примерными данными, RU и UA отдельно.
**Код:** `assets/pdffan.js` (объект FANS), картинки `instrumenty/preview/<инструмент>/N.jpg`; маленький веер в карточке — ToolCard.
