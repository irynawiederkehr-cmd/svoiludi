«Что говорят о «Своих людях»» (`.otzyvy`, с 13.10.2026): главная (в «О проекте»), `o-proekte/`, `dlya-specialistov/`. Тот же вид, что «Что говорят клиенты» на voznesenskaya.ch, в цветах svoiludi.ch.

- Горчичная «бровь», заголовок Forum, серая строка «…Публикуем с их разрешения».
- Карточки листаются вбок (на телефоне 86 % ширины, следующая выглядывает; на компьютере до 400 px): бумага, рамка 1,5 px с горчицей, 20 px; пилюля-метка светлым шалфеем, цитата Forum в горчичных «», до 8 строк, длиннее — «Читать полностью»; имя жирным главным цветом, роль серым, «Карточка в справочнике →». Имя — только с разрешения, иначе «Отзыв участницы».
- Последняя — пунктирная карточка «Свои люди» тебе пригодились?…» с кнопкой «Написать отзыв».
- Стрелки — квадратные 44 px, 12 px, только когда карточки не помещаются и не на сенсорных экранах.
