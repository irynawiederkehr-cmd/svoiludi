# DownloadCheck

Галочка перед скачиванием (решение Ирины 10.10.2026). Защищает Ирину и Alonira.ch AG от упрёков и претензий: человек сам подтверждает, что файл — образец, в нём могут быть ошибки, он всё перепроверит, решение и ответственность за ним.

- Одна плашка на страницу, прямо над первой кнопкой «Скачать PDF», «PNG», «Отправить», «В календарь». Светлая шалфейная заливка, рамка, галочка 22 px, справа кружок «?» («Зачем галочка»).
- Галочка заранее не стоит. Пока её нет, кнопки скачивания серые (`html.svl-dl-off`) и ничего не скачивают. Нажатие на серую кнопку подсвечивает плашку горчичным и подписывает «Сначала отметь галочку, тогда файл скачается».
- Отметка действует, пока страница открыта. Без интернета скачивание работает, запись в «Реестр документов» уходит позже.
- После скачивания внизу экрана напоминание (`.svl-toast`, 14 секунд, крестик): «Перепроверь, прежде чем использовать…» и номер файла.
- У каждого файла свой номер `SL-ГГГГММДД-XXXXXX`, он печатается мелко внизу справа над строкой «Создано на сайте…»: «№ … · подтверждено: это образец» (на языке документа).
- Текст галочки не менять на месте: новая формулировка — новая версия (G2) и строка на листе «Тексты» в таблице.
- На voznesenskaya.ch та же плашка коричневым (`--plum`, `--brand-soft`), текст для тестов — «инструмент для размышления, а не диагноз».

**Код:** `assets/skachivanie.js` (один файл на оба сайта, подключается строкой `<script defer src="/assets/skachivanie.js"></script>`); номер печатают `assets/shema.js`, `wmpdf.js`, `bwprint.js`. Документ проекта — «skachivanie-i-nomer.md».
