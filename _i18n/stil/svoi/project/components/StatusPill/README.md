# StatusPill

Пилюли статуса у каждой строки «Копии svoiludi.ch»: «не размещено» (`pill-bg`, рамка `pill-line`, текст `pill-ink`) и «размещено ДД.ММ.ГГГГ» (контур `sage`, текст `brown`). Метка «Образец» на карточках — тот же цвет, маленькая.

- Правило Ирины: у каждой строки копии статус; после «публикуй» строка получает дату размещения.
- Пилюля — единственное место для `radius-pill` рядом с кнопками.
