# ApplicationForm — форма заявки и галочка согласия

Общий движок `assets/zayavka.js` («События», «Курсы», «Акции», «Вакансии», с 10.10.2026; «Организации» — своя разметка `.form/.fg/.f` с тем же видом). Здесь — начало формы события и конец с галочкой.

- Бумага, рамка 1,5 px, 24 px; заголовок Forum, серая строка «Почти всё выбирается из списков и галочками…».
- Группы `.zfg` с пунктирной линией и подписью маленькими заглавными; **по одному полю в строке**; подпись поля — заглавные серым, звёздочка горчичная, рядом «?»; поля — фон страницы, 14 px, от 50 px высотой; отметки — светлые плашки 12 px с галочкой.
- Вверху у кого есть карточка — «Уже есть в «Своих людях»? Найди свою карточку» по номеру SG-/OR- или UID (`.zlook`, здесь не показан).
- Перед кнопкой — обязательные галочки `.zok` («Это моё событие…», «В моей компетенции…», согласие на обработку данных со ссылкой на политику): вид как DownloadCheck. Пока не отмечены, «Отправить заявку» серая.
- Под кнопкой — сообщение, строка черновика «Всё вписанное сохраняется только на этом устройстве… Удалить историю» и мелкая строка о согласии.
- Каждая новая форма — на этом движке (разметка описана в начале файла).

**Разметка и стили здесь сняты с сайта** скриптом `_i18n/stil/svoi/grab.js` (что снимать — `grab-spec.js`). Поменялся элемент на сайте — `node _i18n/stil/svoi/grab.js ApplicationForm`, руками preview.html и раздел `@grab ApplicationForm` в bundle.css не правим.
