# SiteBadge

Значок проекта для **чужих** сайтов: организации ставят «Мы в «Своих людях»», специалисты — «Я в справочнике» (страница https://svoiludi.ch/badge/, UA /uk/badge/). Ведёт прямо на карточку. Бесплатный, не знак качества и не рекомендация. Светлый и тёмный — с 10.10.2026, белый и чёрный — с 11.10.2026 (просьба Ирины «у людей разные дизайны сайтов»).

- Плашка 280 × 80, скругление 14, слева логотип «круг своих» 54 px, справа три строки: мелкая капитель Manrope 700, главная надпись Forum 23 px, «svoiludi.ch» Manrope 600 11 px.
- Четыре цвета (объект `PAL` в badge/index.html): **светлый** — фон #FFFCF8, рамка #C9D2B6, надпись #4F5E3E; **белый** — #FFFFFF, рамка #D6D6D6, надпись #4F5E3E; **тёмный** — #4F5E3E, рамка #66704F, надпись #FFFCF8; **чёрный** — #111111, рамка #3A3A3A, надпись #FFFFFF. Мелкая строка: горчичная #B98324 на светлых, светлая #F3E3C2 / #E9C77E на тёмных.
- Выбор цвета на странице — четыре карточки `.themes .theme` сеткой 2 × 2 (и на телефоне), в каждой предпросмотр на своём фоне, кружок-радио, название и серая подпись («кремовый, для светлого сайта», «для белого сайта», «зелёный, для тёмного сайта», «для чёрного сайта»).
- Картинки для кода: `badge/img/{org|spec}-{ru|uk}-{light|white|dark|black}.png` (16 штук, 560 × 160), собирает `_i18n/badge_img.js`. **Имена файлов не менять** — на них ссылается код на чужих сайтах.
- Без водяного знака, галочки «это образец» и номера документа: значок — знак проекта, а не документ.
- На voznesenskaya.ch тем же видом внизу каждой страницы стоит «Мой проект «Свои люди»» (ведёт на главную svoiludi.ch) — см. библиотеку voznesenskaya.ch, элемент «Подвал со значком».
