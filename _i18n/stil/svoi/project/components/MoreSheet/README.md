# MoreSheet

Лист снизу по вкладке «Ещё»: остальные разделы, «Поделиться приложением с друзьями», «Обновить страницу» (в приложении на iPhone нет кнопки браузера) и смена языка.

- `paper`, скругление сверху `radius-sheet`, «ручка» 42×5 `line`, заголовок Forum 1,5 rem, пункты — иконка `sage` + текст 16 px жирный, разделители `line`, кнопка «Закрыть» контуром `brown`.
**Код:** `moreSheet()` в `assets/pwa-app.js`.
