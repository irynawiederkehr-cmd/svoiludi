# Gallery

Галерея шагов с картинками телефона (страница «Как установить «Свои люди» на телефон»): на телефоне листается вбок, следующая картинка выглядывает; на компьютере — 4 в ряд.

- Под картинкой номер шага в кружке `sage` и подпись; над галереей — подсказка `small` `muted` («Листай вбок… Нажми, чтобы увеличить»; для макетов — «Картинки примерные…»).
- Нажатие — крупно в `dialog.pr-lb`: тёмный фон, картинка, подпись, «← 2 / 4 →», «Закрыть», листание пальцем.
- На украинской странице — картинки с украинскими надписями (`img/uk/`).
**Код:** `gal()` в `_i18n/struktura_src/build.py`, стили `.pr-gal` в `assets/struktura.css`, картинки — `_i18n/telefon/` (PhoneMockup).
