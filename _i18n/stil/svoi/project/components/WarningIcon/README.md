# WarningIcon

Значок B — светло-красный треугольник с красным «!» (`warn-bg`, `warn-red`), выбран Ириной 09.10.2026.

- Ставится прямо в тексте перед предупреждением, можно посреди абзаца, не как пункт списка: `<i class="wi"></i>`; абзац или пункт получает `class="attn"`.
- Только для: запрещено, только с разрешения кантона или ведомства, штраф, уголовное дело, риск для пермита или денег, жёсткий срок.
- Рядом — выход: что сделать сейчас, где идут навстречу (поддерживающая манера).
**Код:** `.wi` в `assets/temy.css` (SVG внутри CSS), файл значка — `assets/icons/warn-b.svg`; варианты A, C, D — в `biblioteka-znachkov.md`.
