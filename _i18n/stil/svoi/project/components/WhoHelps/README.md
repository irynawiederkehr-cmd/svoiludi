# WhoHelps

Боковой блок статей и «Моей ситуации»: какие категории справочника подходят к теме, настоящие карточки специалистов (если есть) и приглашение «Здесь может быть твоё имя».

- Правило 10.10.2026: справочник только открылся — не обещаем, что специалист есть. Только настоящие карточки (образцы не показываются и не считаются); если их нет — «Справочник только открылся и пополняется. Эти категории в нём есть — посмотри, найдётся ли там специалист для тебя».
- Есть карточки — «По этой теме N специалистов», по 3 штуки, «Показать других →».
- `.box` (`paper`, `radius-hint`), заголовок — `eyebrow`; карточка специалиста — фото 46 px в круге, имя жирным, роль · город `muted`; приглашение — пунктирная рамка, «+» `brown`.
**Код:** `assets/temy.js` (блок `#sp`), стили `assets/temy.css`.
