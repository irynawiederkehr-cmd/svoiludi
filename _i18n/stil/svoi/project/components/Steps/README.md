# Steps

Два вида списков: шаги по порядку и пункты-польза.

- `.todo` — «Что сделать» в конце статей: `paper`, рамка `line` 1,5 px, `radius-sheet`, номера в кружках 28 px `brown` с текстом `paper`. Каждый шаг — полное действие: что, где и как (правила текстов).
- `.okl` — пункты с галочкой (`sage-soft` + зелёная галочка): жирное начало + объяснение. Для «зачем» и «что даст», не для порядка действий.
- Нумерация только там, где порядок важен.
**Код:** `.todo` в `assets/temy.css`, `.okl` в `assets/struktura.css`.
