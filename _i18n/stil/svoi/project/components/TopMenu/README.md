# TopMenu

Шапка обоих сайтов: логотип с названием, «Поиск», кнопка заявки, на телефоне и планшете — разделы плитками в два ряда с иконками, под ними кнопка установки.

- Плитки: `paper`, тонкая рамка шалфея 30 %, `radius-tile`, `shadow-tile`, иконка 22 px линией 1,8 (`sage`), подпись `tile`. Текущий раздел залит `sage` (на voznesenskaya.ch — `brown`), текст `paper`.
- Число колонок подбирается так, чтобы всегда было два ряда (6 разделов — по 3).
- Компьютер: одна строка «логотип · меню текстом · поиск · кнопка»; на 1101–1359 px меню переносится строкой под логотип; текущий пункт — тёмным жирным.
- Разделы svoiludi.ch: Специалисты · Как устроена Швейцария · Полезные инструменты · События и курсы · Что нового · Для специалистов. voznesenskaya.ch: Обо мне · Работа со мной · Продукты · Твой путь · Тесты · Свои люди.
**Код:** блоки `sl-top` и `pa-tiles` в `<head>` (собирает `_i18n/pwa.py`, `topnav.py`), иконки — `topTiles()` в `assets/pwa-app.js`.
