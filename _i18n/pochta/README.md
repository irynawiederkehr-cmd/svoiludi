# Письма в справочник «Свои люди» — скрипты (10.10.2026)

Порядок работы — документ проекта claude.ai «pochta-svoiludi.md» (задача «Свои люди: проверка писем», 08:49 · 12:49 · 17:49).

- `anketa.py <raw.json> <папка>` — письмо Gmail (get_message RAW, сохранённое в файл) → вложения в папку + JSON: заголовки, текст, поля анкеты по подписям, отмеченные галочки, размер фото. `--docx <файл>` — только анкета.
- `kartochka.py <card.json> <фото> [--box x0,y0,x1,y1]` — черновик карточки в data/specialists.js (status «черновик», скрыта; key, added, photo ставятся сами) и фото img/<id>.jpg 480×600. Карточка с тем же id заменяется (SG-номер и key сохраняются).

Данные людей (анкеты, оригиналы фото, письма, проверки реестров) в репозиторий не кладём: он публичный. Их место — папка специалиста на компьютере Ирины («01 Swiss Guide — бесплатный бот\Специалисты — документы (не для сайта)»). Скрипты запускать с `python3 -I`, вложения — только в scratchpad.
