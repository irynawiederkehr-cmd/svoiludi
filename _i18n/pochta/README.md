# Письма в справочник «Свои люди» — скрипты (10.10.2026)

Порядок работы — документ проекта claude.ai «pochta-svoiludi.md» (задача «Свои люди: проверка писем», 08:49 · 12:49 · 17:49).

- `anketa.py <raw.json> <папка>` — письмо Gmail (get_message RAW, сохранённое в файл) → вложения в папку + JSON: заголовки, текст, поля анкеты по подписям, отмеченные галочки, размер фото. `--docx <файл>` — только анкета.
- `zapis.py <письмо.txt> [--write]` — письмо-заявка с сайта (событие, курс, объявление, RU или UA) → черновик записи в data/afisha.js или data/vacancies.js со статусом «на подтверждении» и key. Если человек нашёл в заявке свою карточку (строка «Карточка в справочнике: …»), организатор/автор, кантон, адрес и координаты берутся из карточки, «Другой адрес/телефон/e-mail» — вместо карточки. Печатает ссылку предпросмотра (events|kursy|vakansii/#ok=<id>.<key>) и e-mail, куда её отправлять: всегда e-mail из карточки. Черновик проверить глазами.
- `kartochka.py <card.json> <фото> [--box x0,y0,x1,y1]` — черновик карточки в data/specialists.js (status «на подтверждении», скрыта; key, added, photo ставятся сами) и фото img/<id>.jpg 480×600. Карточка с тем же id заменяется (SG-номер и key сохраняются).
- `chistye_ssylki.py --jsonl <журнал или ответ get_draft> [--html <id>=<файл>] [-o <страница.html>] [<id> …]` — коннектор Gmail сохраняет черновики со ссылками через google.com/url?q=… (с 12.10.2026 проверено: обойти нельзя). Скрипт собирает страницу «Письма с чистыми ссылками»: те же письма с настоящими ссылками, кнопки «Скопировать письмо» и «Открыть черновик в Gmail». Ирина копирует письмо и вставляет в черновик (Ctrl+A, Ctrl+V) перед отправкой. Страница — на компьютере Ирины (в ней ключи предпросмотра), не в репозитории.

Данные людей (анкеты, оригиналы фото, письма, проверки реестров) в репозиторий не кладём: он публичный. Их место — папка специалиста на компьютере Ирины («01 Swiss Guide — бесплатный бот\Специалисты — документы (не для сайта)»). Скрипты запускать с `python3 -I`, вложения — только в scratchpad.
